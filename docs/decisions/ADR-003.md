# ADR-003: Multi-Agent 采用 Agent-as-Tool 委派模式

- **状态**: Accepted
- **日期**: 2026-08-29

## 背景

REQUIREMENTS §41 要求 Multi-Agent 协作（Coordinator / 专项 Agent），通信方式可选
Delegate / Handoff / Agent as Tool / Sub Run。

## 决策

采用 **Agent as Tool**（`packages/agent` 的 `agentToTool`）作为首个协作模式：

- 子 Agent 被包装为普通 `AgentTool`，由父级 Loop 以工具调用方式发起
- 子 Run / Step / Trace 完全独立（自带 runId），不混入父级日志流
- 委派工具 permission 为 free；子 Agent 内部的 approval 级工具仍在
  其自身链路触发审批，安全边界不因委派放宽
- 委派深度由各 Agent 的 maxSteps 约束

## 被否决的备选

- 共享 Loop 的多角色切换：日志流混杂、Token 统计不可分（违反 §47）
- Handoff（控制权完全移交）：状态恢复复杂，延后至有真实场景再做

## 影响

- Coordinator 类 Agent 由 agentToTool 组合专项 Agent 构成
- 后续 Workflow / 图编排复用同一模式
