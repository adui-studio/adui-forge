# ADui Forge

**Agent-Driven Development Platform** — an agent-driven software development platform
for developers and teams: you describe intent and boundaries; agents plan, inspect,
modify, test, fix and deliver; high-risk operations wait for human approval.

## Highlights

- **Custom agents / named models / skill injection** — runtime configuration, no code changes
- **Skill marketplace** — built-in catalog, per-skill install, version-driven update hints,
  paste & bundle import, usage stats
- **Workflow orchestration** — visual conditional-branch graphs, per-node agent selection
  (multi-agent orchestration), run history
- **Workspace IDE** — file tree + Monaco editor + Git panel + agent panel + terminal
- **Local Runner** — desktop local loop (Bun sidecar ships with the installers)
- **Comparison** — side-by-side streaming comparison, cross-batch stats
  (avg duration / avg tokens / fastest wins), CSV / MD export
- **Multi-platform** — Web / Desktop (Tauri) / Mobile (Flutter: view, control, approve)
- **Conversation persistence / task ledger / approval loop / token usage / bilingual UI**

## Installers

[Releases](https://github.com/adui-studio/adui-forge/releases/latest) ships installers for
Windows (NSIS/MSI), macOS (arm64 & x64 DMG), Linux (AppImage/deb) and Android (APK),
built automatically per tag.
