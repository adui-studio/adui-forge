# ADui Forge

**Agent-Driven Development Platform** — 一个面向开发者与研发团队的 Agent 驱动软件开发平台。

开发者描述意图与边界，Agent 负责理解、规划、检索、修改、测试、修复与交付，高风险操作由人工审批。
